# Mix Quest
An  interactive guide to home mixology

Mix Quest is an web app designed for home bartenders who are just getting started — people who want to make a good drink but feel intimidated by vague recipes, technical jargon, and the fear of wasting expensive ingredients.

Instead of another recipe database built for people who already know what they're doing, Mix Quest guides beginners through the process: pick a drink by mood, filter by difficulty, and follow a clear step-by-step mode with visual checkpoints. A light gamification layer (skill badges, progress) turns the learning curve into something worth coming back to, rather than a one-time attempt that ends in frustration.
